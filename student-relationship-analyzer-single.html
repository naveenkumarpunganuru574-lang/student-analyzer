ABOUT THE PROJECT

Set Theory + Relations

A student-friendly demonstration of Discrete Mathematics concepts using real browser data.

01

What the Project Demonstrates

Set Theory

Union, intersection, difference, complement and set membership.

Relations

Ordered pairs, relation matrices and relation properties.

Visualization

Dynamic SVG Venn diagrams with actual student names.

02

Important Difference

Set: collection of students. Relation: collection of ordered pairs. Venn Diagram: visual representation of sets and their intersections. The relation matrix represents ordered-pair relationships, while the Venn diagram represents set membership.

03

Project Flow

Students → Create Student Sets → Assign Students → Create Relationships → Venn Diagram → Set Operations → Relation Matrix → Reflexive / Symmetric / Transitive Analysis → Final Report
